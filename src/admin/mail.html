Почта кабинета

Ящик, с которого кабинет отправляет участницам письма «новый пароль». Пароль ящика сохраняется только на сервере. Перед сохранением сервер отправит пробное письмо — настройки сохранятся, только если оно ушло. Через 1–5 минут в кабинете появится кнопка «Не помню пароль».

Тот же, что в SaleBot (константа site_ingest_key), — из менеджера паролей. Не обычный пароль ящика: в VK WorkSpace / Почте Mail.ru — «Безопасность» → «Пароли для внешних приложений» → создать (доступ: SMTP / отправка).
