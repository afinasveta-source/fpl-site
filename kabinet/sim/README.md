# Симуляция и нагрузка кабинета

Нужна локальная PostgreSQL и служебная база с именем `*_test` (как у тестов). Рабочий сервер не используется.

```sh
cd kabinet
export FPL_SIM_DSN=postgresql://USER:PASS@127.0.0.1:5432/ANY_test
python -m sim.game200 [--keep]      # целая Игра на 200 участниц через HTTP, ~25 минут; находки — sim-report.json
python -m sim.load --cpu 0          # нагрузка на настоящем uvicorn (1 процессор, как сервер); итог — load-report.json
python -m sim.membench 40 80        # память службы при одновременной загрузке фото
```

- `game200` — 5 туров с разными способами выдачи заданий (общее, по лигам со своими датами) и судейства (пары по лигам
  и общим пулом, критерии, переголосование, решение организатора, замена судьи, закрытие недосуженного), сценарии
  участниц (опоздание, личный срок, замена работы, вне конкурса, выход, дисквалификация, смена лиги, новая редакция
  Правил посреди Игры), итоги Игры с подстроенными равенствами, права, выгрузка на сайт, маленькие Игры 03 и 04.
- `oracle.py` — независимый пересчёт по правилам из сырых данных базы (не использует `kabinet.*.compute`):
  баллы БТ и критериев, проход, TOP WORK по лигам, итог 40/60, места, общий список, TOP-10/25, зачёт, дипломы, очки.
- `serve.py` + `screens.py` — поднять кабинет на базе симуляции (`--keep`) и пройти экраны в браузере (390 и 1280 px).
