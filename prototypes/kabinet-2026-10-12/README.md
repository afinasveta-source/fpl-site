# Прототип личных кабинетов FPL — 12.10.2026

Только макет: без настоящих данных, без оплаты и без отправки сообщений. На рабочий сайт не выкладывается
(сайт собирается из `src/` ветки `main`; эта ветка — `kabinet-prototip`).

- `index.html` — кабинет участника. Внизу экрана «Настройки прототипа» — переключатель состояний (новый участник,
  работа сдана, вне конкурса, итог Игры и т. д.).
- `overview/index.html` — кабинет организатора, судьи и модератора (переключатель «Рабочий кабинет» вверху).
- `CHANGES_FOR_REVIEW.txt` — что изменено, решения владельца и открытые вопросы.
