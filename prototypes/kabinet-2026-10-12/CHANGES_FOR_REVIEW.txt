Шаг 4б · Правила вне конкурса уточнены владельцем (11.10.2026)
- Вне конкурса нет сроков туров: задания сдаются когда удобно, но все — до конца Игры.
- Все работы сданы до конца Игры → диплом выдаётся.
- Каждая работа сдана в срок своего тура → Игра ещё и засчитывается.
- Опоздавший может досдать пропущенный тур вне конкурса (тур 2 в демо кликабелен):
  статус тура «Сдана после срока · для диплома». Зачёт Игры у опоздавшего: «Не будет».
- Тексты: главная, Мои Игры, страница Игры (следующий шаг, статус, туры), задание, «срок прошёл».
- Вне конкурса любую сданную работу (и досданную после срока, и текущего тура) можно заменить
  до конца Игры; в списке туров: «Сдана после срока · идёт в диплом» / «Сдана · идёт в диплом» /
  у отсеянного жюри «Сдана в срок тура · идёт в зачёт и диплом».
- На задании вне конкурса для отсеянного жюри дополнительно: «Срок тура для зачёта Игры — …».

Шаг 5 · Задание и сдача работы (11.10.2026)
- Нижняя кнопка рабочая всегда: без фото — «Добавить фото» (открывает камеру/галерею),
  с фото — «Сдать работу 3» (вне конкурса — «Сдать работу N — вне конкурса»; при замене — «Сохранить замену»).
- Срок — компактной строкой: «Сдать до 15 октября, 23:59», под ней часовой пояс и остаток.
- Требования к фото — списком с галочками под заданием (в режиме «только ссылка» — требование к ссылке).
- Вместо «дальнейшие последствия определяются правилами» — «После срока работа в конкурс не идёт —
  продолжить можно вне конкурса».
- Референсы — открытыми картинками сразу под заданием (раньше свёрнуты внизу).
- Поле ссылки: «Ссылка на публикацию · необязательно/обязательно», без служебных фраз прототипа.
- «Работа сдана»: галочка, «Работа к туру 3 сдана», «Итог тура — 17 октября, 14:00», кнопки
  «Заменить работу», «На главную», «Обзор Игры».
- Проверка перед сдачей: «Режим: Конкурс тура» → «Участие: В конкурсе — работу оценит жюри»
  (вне конкурса — «работу не оценивают»); пояснение: «После сдачи фото и ссылку ещё можно поменять —
  до 15 октября, 23:59 МСК. Жюри оценит последнюю сданную версию»; кнопка «Сдать работу 3».
- «Работа сдана»: статус «Сдана»; «Изменить можно до …»; если ссылки нет — «Не добавлена · Добавить ссылку»;
  вместо «После окончания срока на оценивание поступит…» — «Пока срок не закончился, фото и ссылку
  можно менять сколько угодно. Жюри оценит последнюю сданную версию»; кнопка «Изменить фото или ссылку».

Шаг 5б · Подтверждение сдачи окном (11.10.2026, по просьбе владельца)

  показывает окно поверх страницы тура — «Сдать работу к туру 3?», миниатюра фото, участие
  (в конкурсе / вне конкурса), ссылка, срок изменений, кнопки «Сдать работу 3» и «Отмена» (и Esc).
  При замене — «Заменить сданную работу?» / «Сохранить замену». Маршрут review оставлен для старых ссылок.
- Кнопки (по просьбе владельца): в окне и внизу задания — «Сдать работу 3»; если работа уже сдана —
  «Заменить работу 3» (заголовок окна «Заменить работу 3?»). На «Работа сдана» две кнопки:
  «Заменить работу 3» и «Сдать ссылку» (если ссылки нет) / «Заменить ссылку» (если есть);
  ссылочная кнопка показывается, только если тур принимает ссылку. «Сдать ссылку» открывает задание
  сразу на поле ссылки, кнопка и окно — «Сдать ссылку» / «Заменить ссылку».

Шаг А4б · Работы совместного задания (11.10.2026)

Групповые задания — открытые вопросы (решение владельца: отложить, решить позже)

Шаг А5б · Оценивание по критериям, увеличение работ, основа работы (12.10.2026) — решения владельца
Кабинет судьи:
- Сравнение пар: на телефоне работы снова одна под другой; на компьютере — рядом (помещаются без прокрутки).
- Любую работу можно увеличить: нажатие → просмотр на весь экран, переключение «А / Б», «Крупнее» (в 2 раза, с прокруткой),
  «Закрыть», Esc. На телефоне работает обычное увеличение пальцами.
- У каждой работы — плашка «основа работы»: «Свой материал участника» (тема + картинка участника) / «Работа сделана по
  выданному материалу» (оригинал, тоже увеличивается) / «Задание в паре · оцените только эту работу» (работа партнёра для
  контекста). В прототипе вид переключается выбором «Пример основы работ».
- Новый способ: «Оценка по критериям» — одна работа на экране, по каждому критерию шкала 1–10, «Сохранить · среднее 7,3»;
  после всех работ — таблица своих оценок. Пример очереди из 3 работ с разной основой (свой материал / выданный / в паре).
Кабинет организатора, настройки тура:
- Блок «Оценивание»: «Сравнение пар» или «Оценки по критериям — от 1 до 10»; список критериев (добавить / переименовать /
  удалить, до 6); «Срок оценивания». Демо: тур 3 — сравнение пар, тур 4 — Композиция, Идея, Техника; тур 5 — + «Работа в паре».
- «Судьи»: в плашке — срок из настроек тура и способ оценки.
Предложения (логика, нужно решение):
- Итог работы при оценке по критериям — среднее по критериям и по судьям? Нужны ли веса критериев?
- Сколько судей оценивают каждую работу; видит ли судья свои прошлые оценки и может ли их изменить до срока.
- Переголосование на границе (близкие результаты у линии прохода / мест) — делаю в шаге «Результаты»:
  организатор отмечает работы у границы → назначает дополнительное оценивание → судьи получают отдельное назначение.
- Групповые работы — оценка позже, вместе с механикой групп.
Проверено: 1280 и 390 — сравнение (свой / выданный / без материала), увеличение, оценка по критериям до конца,
настройки оценивания туров 3 и 4; кнопки судьи и организатора без ошибок; обход участника без ошибок.

Шаг А5в · Решения владельца по оцениванию (12.10.2026)
- Итог работы при оценке по критериям — среднее с учётом веса критериев, затем среднее по судьям; это число идёт в расчёт.
- Вес критериев настраивается: в настройках тура у каждого критерия поле «вес ×…» — любое число больше 0 (1; 1,25; 2 …).
- Участник после итогов видит свои средние оценки по каждому критерию (только для информации) — в «Итог тура»:
  полоски «Композиция 8,7 · Идея 9,0 · Техника 8,0 (вес ×1,5)». В прототипе участника — переключатель «Способ оценки».
- Обычно работу оценивают 3 судьи — поле «Судей на каждую работу» (по умолчанию 3).
- Судья может изменить оценку или решение до конца срока оценивания: «Изменить» в «Мои решения» и в таблице оценок.
- «Проходят в следующий тур» — теперь и в настройках тура (по лигам; пусто — проходят все); это то же число, что
  в «Результатах» («Сохранить число проходящих»), меняется в обоих местах. Для финального тура — «дальше итог Игры».

Шаг А6б · Переголосование — решения владельца (12.10.2026)
- Переголосование — попарное сравнение; голосуют по умолчанию те же судьи тура (можно снять / добавить).
- Гибко: организатор сам выбирает, какие работы переголосовать (любые в лиге — пара у границы, первые 4 для мест и т.д.),
  и цель: «Решить, кто проходит» или «Распределить места среди выбранных». Судьи сравнивают все пары среди выбранных
  (3 работы → 3 пары, 4 → 6); новый порядок — по числу побед (при равенстве — по баллам тура); места занимают те же
  позиции («1, было 2»). Быстрая кнопка «Переголосование у границы» подставляет пару у границы прохода.
- Судьи не успели к сроку — кнопка «Продлить срок» (новый срок, судьям уведомление).
- Судья проходит пары по очереди («пара 1 из 3»), может вернуться и изменить голоса до срока.
- Открытый вопрос: переголосование в туре с оценками по критериям — пока не решено (в прототипе — тоже попарно).
- Владелец: к механике голосования вернёмся отдельно, подробнее.
События: срок переголосования продлён → судьи → T.
Проверено: 1280 и 390 — у границы (пара), все 3 работы лиги на места, продление срока, голос судьи по 3 парам, итог;
кнопки «Результатов» в трёх состояниях; обходы остальных кабинетов без ошибок.
